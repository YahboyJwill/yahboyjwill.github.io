# JW Portfolio
## Project Scope Statement

### Project Purpose

The purpose of this project is to create a personal website that centralizes my education, work experience, technical skills, and certifications in one professional location. This will allow for potential employers, recruiters, and any professional contacts to learn or find information about my professional background.

### Project Description

This will involve designing and developing a personal portfolio website. The website will provide an organized overview of my professional and educational background while also showcasing my technical abilities and accomplishments.

#### The following sections will be included in the portfolio:

- **About Me**
- **Work Experience**
- **Education**
- **Certifications**
- **Technical Skills**

For this assignment, I will be omitting my contact information other than my TTU contact information.

### Desired Results

My completed website should provide visitors with a clear understanding of my professional background. The website will include all planned portfolio sections, working navigation links, consistent styling, and no major formatting issues. It should also be professional enough to be used outside of the classroom and provide me a fondation that I can continue updating as I earn new certifications, gain additional experience, and move into new career roles. 

### Project Exclusions

#### The following information will not be included:
- **User Account Credentials**
- **Payment Information**
- **Private Personal Information**
- **Contact Information other than my TTU Email**

These features may be looked at once this project is finished for this class.

### Feedback Loops

Feedback will be collected by both the Professor and classmates. Professor Whalen gives really great guidance on how to improve my work to meet the project's rubric and course requirements. I will be able to use this to create the best website that can represent my skills to their fullest potential. Classmates will also provide feedback during peer reviews, focusing on whether my portfolio is clear, organized, professional, and easy to navigate. This feedback will be used to make changes before submitting my final project.

### People Resources

This is my individual project. I am the project manager, web designer, and developer of the website. 

Professor Whalen is the key stakeholder and primary evaluator of my project and will provide guidance on areas for improvement. 

### Project Priorities

- **Quality 1**
Creating a functional website that is organized, and professional. 
- **Time 2** 
My project must be completed and submitted by the course deadline, October 1st 2026.
- **Budget 3**
